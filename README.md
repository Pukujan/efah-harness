# EFAH — Evidence-First Cross-Vendor Engineering Harness and Eval Lab

Contract **EFAH-CONTRACT-001 v1.1** (v1.0 + AMENDMENT-001, owner-approved 2026-08-02).

A contract-compiled, evidence-first, vendor-neutral, long-running multi-agent
software-engineering and assurance platform.

- **LangGraph** is the permanent workflow runtime (DEC-001).
- **TerminusDB** is the authoritative project, ontology, provenance and assurance graph.
- **LiteLLM** is the cross-vendor model gateway; gate-bearing traffic uses the eval
  deployment only (DEC-002).
- **Plane** is a read projection, never project truth.

No essential runtime path depends on Claude access after 2026-08-03.
